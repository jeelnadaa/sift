# Sift launch video: plan

**Angle:** your inbox is loud; Sift lets exactly the mail that matters through, then keeps it in order (company timelines, folders that sort themselves) and in step on every device.
**Hook:** mail rains down onto a mesh, only one glowing card falls through: "Online test · closes tonight".
**Punchline:** "Stop digging. Start sifting."
**Tone:** cinematic but clean (owner: production level, fluid motion, real narration, kinetic captions).
**Format:** 1920×1080, 30 fps, 32 s (16 bars at 120 BPM; one beat = 0.5 s; every cut on a beat).

**Visual identity (from the code):** background #0a0a0b, surfaces #151518 / #1c1c20, text #f4f3ee, lime #c8ff3d, tiers urgent #ff5a3c / normal #6ea8ff / digest #b79cff; Clash Display for headlines, Satoshi for everything else; corners 4–14 px; the traced logo (three lime layers + "sift" wordmark).

**Real UI:** web screens are the real built app (its own CSS bundle and fonts), captured from a throwaway test server seeded with fictional data, then animated element by element. Phone screens are the real Compose screens rendered from the Android code (Paparazzi) with the same fictional data.

**Fictional data (nothing real is shown):** companies Acme Corp and Globex, test platform "AssessHub", bank "Northbank", recruiter "Riya (Globex)", accounts "Personal" and "College" (you@…).

**Narration:** Microsoft neural voice "Andrew" (en-US), warm and natural, compressed and ducked over the music like an ad read. Kinetic captions under the picture, each word turning lime as it's spoken.

**Music:** original, 120 BPM, A minor (Am–F–C–G): soft pad and filtered pluck in the hook, kick and sub bass land on the reveal, a lift into the outro, resolving on the logo. Effects (whooshes, ticks, a shimmer) in the same key, tucked under the music.
